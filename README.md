 *A cool looking clock

A fun little project that tries to improve on the iPhone’s StandBy (nightstand) mode. It’s a full-screen, glowing digital clock for a phone, tablet or any screen you want to leave on a desk or nightstand.

What makes it different
Overlapping digits: big, bold numbers that tuck into each other for a chunky, layered look.
Floating motion: every digit, the colon and each character of the date drifts gently on its own timing, so the clock feels alive instead of static.
Neon glow: the digits and date glow against a pure black background, which suits OLED screens and dark rooms.
Auto-hiding controls: the interface fades away after a moment of inactivity, leaving only the clock (and the date, if you choose).
Customization
10 color themes, including Vibrant Blue, StandBy Orange, Neon Green, Pure Pink and Night Red
A custom two-color picker for your own palette
Glow level slider
Three font choices: Fredoka, Nunito and Outfit
12-hour or 24-hour format
Optional seconds display
Option to keep the date visible at all times
One-tap fullscreen
Built with

Plain HTML, CSS and JavaScript, with Tailwind (CDN) for styling and Lucide for icons. There’s no build step. Open index.html in a browser and it runs.
